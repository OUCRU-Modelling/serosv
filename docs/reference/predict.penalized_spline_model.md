# Prediction for serosv penalized spline model

Prediction for serosv penalized spline model

## Usage

``` r
# S3 method for class 'penalized_spline_model'
predict(object, newdata = NULL, ...)
```

## Arguments

- object:

  serosv models

- newdata:

  data.frame with age column to generate prediction

- ...:

  arbitrary argument

## Value

prediction output
