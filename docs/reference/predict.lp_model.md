# Prediction for serosv local polynomial model

Prediction for serosv local polynomial model

## Usage

``` r
# S3 method for class 'lp_model'
predict(x, newdata = NULL, ...)
```

## Arguments

- x:

  serosv models

- newdata:

  data.frame with age column to generate prediction

- ...:

  arbitrary argument

## Value

prediction output
