# Prediction for serosv fractional polynomial model

Prediction for serosv fractional polynomial model

## Usage

``` r
# S3 method for class 'fp_model'
predict(object, newdata = NULL, ...)
```

## Arguments

- object:

  serosv models

- newdata:

  data.frame with age column to generate prediction

- ...:

  arbitrary argument

## Value

prediction output
